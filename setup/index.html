      Classifier

      Decides whether a posted file is a research report.

        Local model server

        Any OpenAI-compatible server, such as llama.cpp or LM Studio, reachable from where the bot runs.

        Prompt

        A .txt file with one pattern per line. A file counts as a report if any pattern matches its text.

        Example reports

        Past reports help the Classifier identify new reports better.

        Summarizer

        Summarizes a research report and works out which week it covers.

          Prompt

          Finds the week a report covers. The first group in brackets is the week number. Without a match, the week comes from the post date.

          Link to Work

          Searches GitHub for links to work mentioned in the report.

            Prompt

            The bot tries to match pull requests in this repository to work mentioned in each report

            GitHub usernames

            Which GitHub username belongs to each researcher.
