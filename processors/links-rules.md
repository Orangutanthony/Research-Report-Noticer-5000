# Linking work

Link a pull request or URL only if one of the summary bullets describes the work in it. Being from the right week is not enough.

A link from the report counts only if it is the researcher's own work, such as a branch, commit or file they made. Tools, libraries, datasets, papers and other people's repositories they used or cited do not count. Decide from the sentence the link appears in, not from the URL.

When unsure, leave it out. A wrong link is worse than no link.
